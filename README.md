# EXNO: 6 JavaScript Calculator

## AIM:
To design and develop a simple and attractive calculator using HTML, CSS, and JavaScript.

## ALGORITHM:
1.Start the program and create the calculator structure using HTML with a display screen and buttons for numbers and operators.
2.Design the calculator using CSS by adding colours, spacing, borders, button styles, and a suitable layout.
3.Capture the button clicks using JavaScript and display the selected numbers and operators on the calculator screen.
4.Perform the required arithmetic operation such as addition, subtraction, multiplication, or division using JavaScript.
5.Display the calculated result on the screen and provide a Clear button to reset the calculator.
